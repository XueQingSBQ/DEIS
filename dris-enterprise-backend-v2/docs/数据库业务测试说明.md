# DRIS 后端业务与数据库测试说明

## 1. 当前后端业务逻辑（v2）

### 1.1 标识核心（`/api/v2/identifiers`）
- `POST /register`：按 SDK 规则校验注册请求并生成标识，写入 `identifier_metadata`。
- `POST /register/batch`：批量生成标识。
- `GET /{identifier}/validate`：仅做标识格式校验。
- `GET /{identifier}/exists`：校验标识是否存在。
- `GET /{identifier}/metadata`：查询元数据。
- `POST /resolve/batch`：批量解析元数据。
- `GET /{identifier}/object`：查询数字对象（元数据 + 组件）。
- `PUT /{identifier}/metadata`：全量更新元数据。
- `PATCH /{identifier}/metadata`：局部更新元数据。
- `DELETE /{identifier}`：删除标识（业务删除）。

### 1.2 资源组件（`/api/v2/identifiers/{identifier}/component`）
- `PUT`：绑定或更新组件资源。
- `GET`：查询组件资源。
- `DELETE`：移除组件资源。

### 1.3 搜索（`/api/v2/search`）
- 按关键词/自然语言进行检索，返回匹配结果。

### 1.4 上传下载（`/api/v2`）
- `POST /identifiers/{identifier}/upload-sessions`：创建上传会话。
- `POST /upload-sessions/{uploadId}/complete`：完成上传并回写组件。
- `POST /downloads/presign`：生成下载预签名结果。

### 1.5 运维（`/api/v2/ops`）
- `POST /vector/sync`：触发向量索引同步。
- `GET /metrics`：获取业务指标快照。

## 2. 数据库真实集成测试

测试类：`src/test/java/com/dris/v2/backend/integration/BackendDbBusinessIntegrationTest.java`

- `invalidIdentifierRule_shouldBeRejectedBySdkValidation`
  - 覆盖非法标识 `id-1` 的 `validate/exists/metadata` 返回路径。
- `currentBackendBusinessApis_shouldWorkOnMysql`
  - 覆盖当前所有已实现的 controller 业务接口：
  - 注册、批量注册、校验、存在性、解析、批量解析、对象查询。
  - 元数据全量更新、局部更新。
  - 组件 upsert/get/delete。
  - 搜索。
  - 上传会话创建、上传完成、下载预签名。
  - 向量同步、指标查询。
  - 删除与删除后存在性校验。

## 3. 数据库兼容修正

为适配旧库结构与 SDK 当前写入格式，已加入兼容处理：

- `schema.sql` 增加迁移：
  - `identifier_metadata.create_time/update_time` 改为 `VARCHAR(64)`。
  - `resource.created_at` 改为 `VARCHAR(64)`。
  - `upload_session.expires_at` 改为 `VARCHAR(64)`。
- 新增 `IsoUploadSessionRepository`：
  - 过期判断改为按 ISO-8601 字符串解析，避免字符串与 `NOW()` 比较误判。
