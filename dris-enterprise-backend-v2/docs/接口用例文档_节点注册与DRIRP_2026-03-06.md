# 节点注册与 DRIRP 用例（精简版，2026-03-06）

## 1. 范围

- HTTP：`/api/v2/node/register`、`/api/v2/node/direct-descendants`、`/api/v2/node/routes`
- DRIRP：`NODE_UNIQUENESS_CHECK_UP(7101)`、`NODE_HELLO(7102)`、`ROUTE_INSERT_UP(7103)`

## 2. 字段约定（已更新）

- 节点展示名：`nodeName` / `childNodeName`
- 节点编码（主键语义）：`nodeCode = regionCode + orgCode`（例：`3701WXYZ`）
- 路由下一跳：`nextHopCode`（不再使用下一跳节点名）

## 3. HTTP 用例

### 3.1 注册子节点

`POST /api/v2/node/register`

请求：

```json
{
  "childNodeName": "node-city",
  "regionCode": "3701",
  "orgCode": "WXYZ",
  "childDrirpUrl": "grpc://127.0.0.1:39093"
}
```

成功响应（关键字段）：

```json
{
  "ok": true,
  "data": {
    "childNodeName": "node-city",
    "childLevel": "CITY",
    "bootstrapConfig": {
      "nodeName": "node-city",
      "parentNodeName": "node-province"
    }
  }
}
```

### 3.2 查询直连后代

`GET /api/v2/node/direct-descendants`

响应（关键字段）：

```json
{
  "ok": true,
  "data": [
    {
      "childCode": "3701WXYZ",
      "childNodeName": "node-city",
      "childRegionCode": "3701",
      "childOrgCode": "WXYZ",
      "relationStatus": "ACTIVE"
    }
  ]
}
```

### 3.3 查询路由表

`GET /api/v2/node/routes`

响应（关键字段）：

```json
{
  "ok": true,
  "data": [
    {
      "targetCode": "3701WXYZ",
      "targetNodeName": "node-city",
      "nextHopCode": "3700ABCD",
      "hopCount": 2
    }
  ]
}
```

## 4. DRIRP 消息样例

### 4.1 NODE_HELLO

```json
{
  "nodeName": "node-city",
  "nodeCode": "3701WXYZ",
  "regionCode": "3701",
  "orgCode": "WXYZ",
  "drirpUrl": "grpc://127.0.0.1:39093"
}
```

### 4.2 ROUTE_INSERT_UP

```json
{
  "targetRegionCode": "3701",
  "targetOrgCode": "WXYZ",
  "targetNodeName": "node-city",
  "senderCode": "3700ABCD",
  "senderNodeName": "node-province",
  "distanceFromSender": 1
}
```

> 兼容说明：服务端仍兼容旧字段 `nodeId/targetNodeId/senderNodeId`，但新接入建议使用新字段。
