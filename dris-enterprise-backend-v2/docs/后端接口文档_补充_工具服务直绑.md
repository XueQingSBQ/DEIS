# 后端接口文档补充：工具/服务直绑（不上传对象仓库）

## 1. 目标

当数字对象是“可执行工具”或“远程服务”时，不必先上传二进制到 COS，可直接在 `resource` 表登记位置与调用说明。

适用接口：

- `PUT /api/v2/identifiers/{identifier}/component`
- `GET /api/v2/identifiers/{identifier}/component`

## 2. 工具直绑示例

请求：

```json
{
  "componentType": "tool",
  "role": "primary",
  "storageType": "local_exec",
  "accessMethod": "invoke",
  "contentType": "tool",
  "format": "json",
  "locator": "local://tools/sum-cli",
  "size": 0,
  "hashValue": "",
  "extra": {
    "operationName": "sum",
    "operationDesc": "本地求和工具",
    "argTemplate": "{\"a\":${a},\"b\":${b}}",
    "input_schema": {
      "type": "object",
      "required": ["a", "b"]
    },
    "output_schema": {
      "type": "number"
    }
  }
}
```

成功响应（简化）：

```json
{
  "ok": true,
  "code": "OK",
  "data": true
}
```

## 3. 服务直绑示例

请求：

```json
{
  "componentType": "service",
  "role": "primary",
  "storageType": "api_service",
  "accessMethod": "api_call",
  "contentType": "service",
  "format": "openapi_json",
  "locator": "https://api.example.com/v1/sum",
  "size": 0,
  "extra": {
    "operationName": "sum",
    "operationDesc": "远程求和服务",
    "method": "POST",
    "path": "/v1/sum",
    "timeoutMs": 3000
  }
}
```

查询响应（简化）：

```json
{
  "ok": true,
  "code": "OK",
  "data": {
    "componentType": "service",
    "storageType": "api_service",
    "accessMethod": "api_call",
    "contentType": "service",
    "locator": "https://api.example.com/v1/sum",
    "extra": {
      "operationName": "sum"
    }
  }
}
```

## 4. 校验规则

### 4.1 tool

- `componentType` 必须为 `tool`
- `contentType` 必须为 `tool`
- `storageType/accessMethod/format/locator` 必填
- 当 `require-tool-sha256=false` 时，`hashValue` 可为空

### 4.2 service

- `componentType` 必须为 `service`
- `storageType` 必须为 `api_service`
- `accessMethod` 必须为 `api_call`
- `contentType` 必须为 `service`
- `locator` 必须以 `http://` 或 `https://` 开头

无效示例（会返回 `VALIDATION_ERROR`）：

```json
{
  "componentType": "service",
  "storageType": "api_service",
  "accessMethod": "api_call",
  "contentType": "service",
  "format": "openapi_json",
  "locator": "grpc://service.local/sum"
}
```

## 5. 与 COS 上传的关系

- `resource` 大文件：推荐走上传会话（`/upload-sessions`）
- `tool/service` 描述性或本地执行对象：推荐直绑（`PUT /component`）
- 两种方式共享同一 `resource` 统一交互模型，前端与 SDK 可统一读取
