# 本地搜索增强说明（V2）

## 1. 目标

当前先完善单节点本地搜索能力，保持统一接口：

- `POST /api/v2/search`

增强点：

- 支持按资源组件维度过滤：`componentType/storageType/accessMethod/contentType/format`
- 支持更多检索字段：元数据字段 + 资源字段
- 搜索结果直接返回元数据摘要和资源摘要，便于前端列表展示
- 已接入向量检索（本地 MySQL 向量索引 + 余弦召回）

## 2. 请求模型

请求体沿用 `SearchRequest`：

```json
{
  "naturalQuery": "sum service",
  "keywords": ["sum", "api"],
  "fields": [
    "name",
    "description",
    "componentType",
    "contentType",
    "locator"
  ],
  "filters": {
    "componentType": "service",
    "accessMethod": "api_call",
    "industry": "农业"
  },
  "limit": 10,
  "offset": 0,
  "mode": "HYBRID",
  "semanticWeight": 0.7
}
```

### 2.1 `fields` 支持项

- `name`
- `description`
- `applicationScenario` / `application_scenario`
- `identifier`
- `owner`
- `industry`
- `dataCategory`
- `registrationType`
- `entityType`
- `componentType`
- `storageType`
- `accessMethod`
- `contentType`
- `format`
- `locator`

### 2.2 `filters` 支持项

- 元数据过滤：`industry` `status` `entityType` `dataCategory` `owner` `registrationType`
- 资源过滤：`componentType` `storageType` `accessMethod` `contentType` `format`

### 2.3 模式说明

- `KEYWORD`：关键词检索
- `SEMANTIC`：向量召回优先；若索引未同步/无命中，会自动回退到本地语义近似评分
- `HYBRID`：关键词 + 向量融合重排；若无向量命中，自动降级为关键词排序

## 3. 向量索引使用

在新增/更新标识后，调用一次：

- `POST /api/v2/ops/vector/sync`

用于把 `vector_dirty=1` 的元数据同步到 `identifier_vector_index`。

## 3. 返回结果增强

返回仍为统一 `ApiResponse<List<SearchResult>>`，其中单条 `SearchResult` 新增：

- 元数据摘要：`owner` `industry` `dataCategory` `registrationType` `entityType` `updateTime`
- 资源摘要：`componentType` `storageType` `accessMethod` `contentType` `format`
- 数据来源：`source`（当前本地固定为 `local`）

示例：

```json
{
  "ok": true,
  "code": "OK",
  "data": [
    {
      "identifier": "1100ABCD013120260306xxxxxx",
      "name": "search_local_service",
      "description": "Realtime road traffic flow dataset",
      "owner": "city-traffic-center",
      "industry": "农业",
      "dataCategory": "个人数据",
      "registrationType": "数据产品/服务",
      "entityType": "dataset",
      "updateTime": "2026-03-06T12:00:00Z",
      "componentType": "service",
      "storageType": "api_service",
      "accessMethod": "api_call",
      "contentType": "service",
      "format": "openapi_json",
      "source": "local",
      "keywordScore": 0.76,
      "semanticScore": 0.31,
      "finalScore": 0.56
    }
  ]
}
```
