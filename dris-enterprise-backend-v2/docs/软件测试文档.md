## 2. 测试目标

- 验证已融合 `dris-sdk` 的后端功能在接口层和服务层行为正确。
- 验证关键异常路径（参数错误、资源不存在、业务冲突）可被正确返回。
- 保障回归时核心链路（标识、组件、搜索、上传、运维）不退化。

## 3. 测试范围

本次范围（已测）：

- 标识核心：注册、批量注册、校验、存在性、解析、批量解析、对象查询、全量更新、局部更新、删除
- 组件资源：查询、绑定/更新、删除
- 搜索：搜索请求
- 上传下载：创建上传会话、完成上传、下载预签名
- 运维：向量同步、指标快照

本次不在范围（待补）：

- DRIRP 跨节点解析链路联调
- 多节点联邦搜索汇总
- 大规模压测与稳定性压测

## 4. 测试环境

- OS：Windows 11
- JDK：1.8
- 构建工具：Maven
- 测试框架：JUnit 5 + Mockito + Spring MockMvc
- 数据库：MySQL（业务运行环境），测试主要为 Mock 层自动化

## 5. 测试策略

- 服务层单元测试：
- 验证参数校验和 `DrisClient` 调用委派
- 覆盖空值、空字符串、字段不一致、边界输入
- 控制器层 WebMvc 测试：
- 验证 HTTP 状态码、响应模型、错误码映射
- 覆盖成功、`400`、`404`
- 回归门禁：
- 每次变更执行 `mvn test`
