# 中央认证服务器拆分说明（2026-03-07）

## 1. 结果

本次已把“中央认证服务器”从 `dris-enterprise-backend-v2` 中拆出，形成独立工程：

- `dris-auth-center`

当前职责边界：

### 1.1 中央认证服务器 `dris-auth-center`

负责：

- 用户注册
- 用户登录
- JWT access token 签发
- 公钥发布
- userinfo 查询

核心代码：

- `src/main/java/com/dris/auth/center/auth/AuthController.java`
- `src/main/java/com/dris/auth/center/auth/AuthService.java`
- `src/main/java/com/dris/auth/center/auth/JwtTokenService.java`
- `src/main/java/com/dris/auth/center/auth/AuthUserDao.java`

### 1.2 业务节点 `dris-enterprise-backend-v2`

现在只保留：

- Bearer token 验签
- 当前用户上下文提取
- 本地对象写权限校验
- 跨节点下载 / 工具执行时透传 userId

核心代码：

- `src/main/java/com/dris/v2/backend/auth/JwtTokenVerifier.java`
- `src/main/java/com/dris/v2/backend/auth/AuthCenterPublicKeyProvider.java`
- `src/main/java/com/dris/v2/backend/auth/JwtAuthenticationInterceptor.java`
- `src/main/java/com/dris/v2/backend/service/IdentifierPermissionService.java`

## 2. 接口边界

### 2.1 只在中央认证服务器提供的接口

- `POST /auth/register`
- `POST /auth/login`
- `POST /oauth2/token`
- `GET /auth/public-key`
- `GET /auth/userinfo`
- `GET /oauth2/userinfo`

### 2.2 业务节点不再提供

- 不再承担注册用户
- 不再承担登录
- 不再签发 token
- 不再暴露认证中心接口

## 3. 业务节点如何验签

业务节点新增配置：

```yaml
dris:
  v2:
    auth:
      api-auth-required: true
      write-permission-enabled: true
      issuer: auth-center
      audience: dris-business-node
      auth-center-base-url: http://127.0.0.1:8290
      public-key-pem: ""
      public-key-refresh-ms: 300000
```

说明：

- 优先使用 `public-key-pem`
- 如果没配 `public-key-pem`，则自动向 `auth-center-base-url/auth/public-key` 拉取公钥
- 拉到后按缓存周期复用
