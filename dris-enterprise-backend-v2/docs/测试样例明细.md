# 测试样例明细（逐测试方法）

规则样例标识（符合 dris-sdk 30 位校验规则）：

- `ID1 = 1100ABCD0211202603051234567895`
- `ID2 = 1100ABCD021120260305ABCDE1234E`
- `ID_NOT_FOUND = 1100ABCD021120260305ZZZZZ99991`

## 1. 控制器层

### 1.1 IdentifierCoreControllerTest

| 测试方法 | 样例输入 | 期望结果 |
|---|---|---|
| `register_shouldReturnOk` | `POST /identifiers/register` + 完整 `RegistrationRequest`（`registrationType=resource`） | `200`，返回 `ID1` |
| `metadata_notFound_shouldReturn404` | `GET /identifiers/ID_NOT_FOUND/metadata` | `404`，`code=NOT_FOUND` |
| `metadata_shouldReturnOk` | `GET /identifiers/ID1/metadata` | `200`，`ok=true` |
| `registerBatch_shouldReturnOk` | `POST /identifiers/register/batch` + 2 个完整 `RegistrationRequest` | `200`，返回两个标识 |
| `patchMetadata_validationError_shouldReturn400` | `PATCH /identifiers/ID1/metadata` + `{}` | `400`，`VALIDATION_ERROR` |
| `updateMetadata_shouldReturnOk` | `PUT /identifiers/ID1/metadata` + 完整 `IdentifierMetadata` | `200`，`data=true` |
| `delete_shouldReturnOk` | `DELETE /identifiers/ID1` | `200`，`data=true` |
| `resolveBatch_shouldReturnOk` | `POST /identifiers/resolve/batch` + `[ID1,ID2]` | `200`，`ok=true` |
| `validate_shouldReturnOk` | `GET /identifiers/ID1/validate` | `200`，`data=true` |
| `exists_shouldReturnOk` | `GET /identifiers/ID1/exists` | `200`，`data=true` |
| `object_shouldReturnOk` | `GET /identifiers/ID1/object` | `200`，`ok=true` |
| `resolveBatch_validationError_shouldReturn400` | `POST /identifiers/resolve/batch` + `[]` | `400`，`VALIDATION_ERROR` |
