# 接口用例文档（资源获取/下载预签名/跨节点工具执行/全网搜索，2026-03-07）

## 1. 范围

- HTTP：`GET /api/v2/identifiers/{identifier}/component`
- HTTP：`POST /api/v2/downloads/presign`
- HTTP：`POST /api/v2/identifiers/{identifier}/tool/execute`
- HTTP：`POST /api/v2/search/global`
- DRIRP：`RESOLVE_FORWARD(7201)`，`resolveType=RESOURCE`
- DRIRP：`OP_FORWARD(7301)`，`operationType=TOOL_EXECUTE | DOWNLOAD_PRESIGN`
- DRIRP：`SEARCH_FORWARD(7401)`，`phase=LOCATE_ANCHOR | SEARCH_SUBTREE`

## 2. 设计口径

### 2.1 资源获取

- `component` 获取走统一跨节点归属解析链。
- 本地先按 `identifier -> targetCode(regionCode + orgCode)` 判断归属。
- 非本地按路由表或父节点 fallback 转发 `RESOLVE_FORWARD`。
- `resolveType` 支持：`METADATA` / `DIGITAL_OBJECT` / `RESOURCE`。

### 2.2 工具执行

- `tool/execute` 不在入口节点直接执行。
- 入口按标识归属转发，目标节点本地执行并返回。
- 响应保留 `handledByNodeCode` 标记真实执行节点。

### 2.3 下载预签名

- `downloads/presign` 进入统一跨节点归属操作链。
- 入口按标识归属转发 `OP_FORWARD(DOWNLOAD_PRESIGN)`。

### 2.4 跨节点全网搜索

- 本地检索接口保持不变：`POST /api/v2/search`。
- 全网检索新增：`POST /api/v2/search/global`。
- `anchorNodeCode` 指定锚点子树；为空时默认入口子树。
- `strategy=RECURSIVE`：节点递归聚合。
- `strategy=ITERATIVE`：入口节点迭代定位锚点并迭代遍历子树。

## 3. HTTP 用例

### 3.1 获取组件信息（本地或跨节点）

`GET /api/v2/identifiers/{identifier}/component`

```http
GET /api/v2/identifiers/4201AGGG019320260307LT5XWCA3US/component
```

### 3.2 跨节点工具执行

`POST /api/v2/identifiers/{identifier}/tool/execute`

```json
{
  "args": {
    "a": 7,
    "b": 5
  },
  "timeoutMs": 5000
}
```

### 3.3 跨节点下载预签名

`POST /api/v2/downloads/presign`

```json
{
  "identifier": "4201AGGG019320260307LT5XWCA3US",
  "expiresInSeconds": 600
}
```

### 3.4 跨节点全网搜索

`POST /api/v2/search/global`

```json
{
  "naturalQuery": "global search marker county b",
  "mode": "KEYWORD",
  "strategy": "ITERATIVE",
  "anchorNodeCode": "1100AAAA",
  "ttl": 16,
  "maxFanout": 16,
  "perNodeLimit": 20,
  "limit": 20,
  "offset": 0
}
```

响应要点：

- `data.items[*].identifier` 命中目标标识
- `data.items[*].source` 为归属节点编码
- `data.anchorNodeCode` 回显锚点
- `data.visitedNodeCodes` 展示访问轨迹
- `data.partial=true` 表示部分分支失败但整体可用

## 4. DRIRP 消息样例

### 4.1 资源获取转发（`RESOLVE_FORWARD`）

```json
{
  "identifier": "4201AGGG019320260307LT5XWCA3US",
  "resolveType": "RESOURCE",
  "ttl": 8,
  "visitedUrls": []
}
```

### 4.2 工具执行转发（`OP_FORWARD`）

```json
{
  "identifier": "4201AGGG019320260307LT5XWCA3US",
  "operationType": "TOOL_EXECUTE",
  "ttl": 8,
  "visitedUrls": [],
  "toolExecuteRequest": {
    "args": {
      "a": 7,
      "b": 5
    },
    "timeoutMs": 5000
  }
}
```

### 4.3 下载预签名转发（`OP_FORWARD`）

```json
{
  "identifier": "4201AGGG019320260307LT5XWCA3US",
  "operationType": "DOWNLOAD_PRESIGN",
  "ttl": 8,
  "visitedUrls": [],
  "downloadPresignRequest": {
    "identifier": "4201AGGG019320260307LT5XWCA3US",
    "expiresInSeconds": 600
  }

```


## 5. 当前实现边界

- 已实现：`RESOURCE` 跨节点获取。
- 已实现：`TOOL_EXECUTE` 跨节点递归/迭代两种模式。
- 已实现：`DOWNLOAD_PRESIGN` 跨节点递归/迭代两种模式。
- 已实现：`SEARCH_FORWARD(7401)`，支持锚点定位与子树搜索。
- 已实现：`/api/v2/search/global` 递归/迭代双模式。

## 6. 后续建议

- 搜索：增加全局 deadline/hop timeout 的硬约束执行。
- 搜索：增加并发 fan-out、分层熔断、结果缓存策略。
- 工具执行：增加参数 schema 校验、输出体积限制、审计日志。
