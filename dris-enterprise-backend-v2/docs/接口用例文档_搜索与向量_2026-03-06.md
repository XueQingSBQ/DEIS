# 接口用例文档（搜索与向量检索）

## 1. 文档说明

- 项目：`dris-enterprise-backend-v2`
- 版本：`v2`
- 日期：`2026-03-06`
- 目标：给出可直接联调/测试的接口用例（含请求、响应、异常场景）

## 2. 通用约定

- Base URL：`http://localhost:8080`
- 统一返回格式：

```json
{
  "ok": true,
  "code": "OK",
  "message": "success",
  "data": {}
}
```

- 失败返回示例：

```json
{
  "ok": false,
  "code": "VALIDATION_ERROR",
  "message": "query must not be blank",
  "data": null
}
```

## 3. 接口用例

### 3.1 标识搜索（关键词）

- 方法/路径：`POST /api/v2/search`
- 场景：按关键词检索数字对象（本地）

请求：

```json
{
  "query": "农业遥感",
  "mode": "KEYWORD",
  "limit": 10
}
```

成功响应（示例）：

```json
{
  "ok": true,
  "code": "OK",
  "message": "success",
  "data": {
    "total": 1,
    "items": [
      {
        "identifier": "88.1000.2/AGRI/2026/0001",
        "title": "农业遥感监测数据",
        "semanticScore": null,
        "summary": {
          "metadataType": "DATASET",
          "industry": "农业",
          "resourceCount": 2,
          "componentType": "TOOL"
        }
      }
    ]
  }
}
```

### 3.2 标识搜索（向量语义）

- 方法/路径：`POST /api/v2/search`
- 前置：先执行向量同步接口（见 3.4）

请求：

```json
{
  "query": "农作物长势分析",
  "mode": "SEMANTIC",
  "limit": 5
}
```

成功响应（示例）：

```json
{
  "ok": true,
  "code": "OK",
  "message": "success",
  "data": {
    "total": 1,
    "items": [
      {
        "identifier": "88.1000.2/AGRI/2026/0001",
        "title": "农业遥感监测数据",
        "semanticScore": 0.8731,
        "summary": {
          "metadataType": "DATASET",
          "industry": "农业",
          "resourceCount": 2
        }
      }
    ]
  }
}
```

### 3.3 标识搜索（混合检索）

- 方法/路径：`POST /api/v2/search`
- 场景：关键词 + 语义融合

请求：

```json
{
  "query": "农业遥感",
  "mode": "HYBRID",
  "limit": 10,
  "filters": {
    "componentType": "TOOL",
    "accessMethod": "INLINE"
  }
}
```

成功响应（示例）：

```json
{
  "ok": true,
  "code": "OK",
  "message": "success",
  "data": {
    "total": 1,
    "items": [
      {
        "identifier": "88.1000.2/AGRI/2026/0001",
        "title": "农业遥感监测数据",
        "semanticScore": 0.8124,
        "summary": {
          "componentType": "TOOL",
          "accessMethod": "INLINE",
          "resourceCount": 1
        }
      }
    ]
  }
}
```

### 3.4 向量索引同步

- 方法/路径：`POST /api/v2/ops/vector/sync`
- 场景：把最新元数据同步进向量索引，供 `SEMANTIC/HYBRID` 使用

请求：

```json
{}
```

成功响应（示例）：

```json
{
  "ok": true,
  "code": "OK",
  "message": "success",
  "data": {
    "synced": 12,
    "skipped": 0
  }
}
```

### 3.5 参数校验失败用例

- 方法/路径：`POST /api/v2/search`
- 场景：`query` 为空

请求：

```json
{
  "query": "",
  "mode": "KEYWORD"
}
```

期望响应：HTTP `400`

```json
{
  "ok": false,
  "code": "VALIDATION_ERROR",
  "message": "query must not be blank",
  "data": null
}
```

## 4. 建议联调顺序

1. 先调用 `POST /api/v2/ops/vector/sync`。
2. 调用 `POST /api/v2/search`，分别测试 `KEYWORD/SEMANTIC/HYBRID`。
3. 加上 `componentType/accessMethod` 过滤验证前端筛选。
